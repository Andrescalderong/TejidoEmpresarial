In some implementations, machine learning models
12664 can be or may include one or more artificial neural
networks (also referred to simply as neural networks). A
neural network can include a group of connected nodes,
which also can be referred to as neurons or perceptrons. A
neural network can be organized into one or more layers.
Neural networks that include multiple layers can be referred
to as "deep" networks. A deep network can include an input
layer, an output layer, and one or more hidden layers
positioned between the input layer and the output layer. The
nodes of the neural network can be connected or non-fully
connected.
Machine learning models 12664 can be or include one or
more feed forward neural networks. In feed forward net-
works, the connections between nodes do not form a cycle.
For example, each connection can connect a node from an
earlier layer to a node from a later layer.
