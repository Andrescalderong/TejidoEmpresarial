The activation function determines the activity level or
excitation level generated in the node as a result of an input
signal of a particular size. The purpose of the activation
function is to introduce non-linearity into the output of a
neural network node because most real-world functions are
non-linear and it is desirable that the neurons can learn these
non-linear representations. Several activation functions may
be used in an artificial neural network. One example acti-
vation function is the sigmoid function o(x), which is a
continuous S-shaped monotonically increasing function that
asymptotically approaches fixed values as the input
approaches plus or minus infinity. The sigmoid function o(x)
takes a real-valued input and transforms it into a value
between 0 and 1:
o(x)=1/(1+exp(x).
Another example activation function is the tan h function,
which takes a real-valued input and transforms it into a value
within the range of 1-1, 11:
tan h(x)=20(2x)-1
A third example activation function is the rectified linear
5 unit (ReLU) function. The ReLU function takes a real-
valued input and thresholds it above zero (i.e., replacing
negative values with zero):
f(x)=max(0,x).
