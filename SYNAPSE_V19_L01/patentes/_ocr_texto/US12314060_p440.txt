Reinforcement Learning is a machine learning technique
for learning optimal behavior in an environment by taking
actions and getting feedback, similar to how humans and 60
animals learn by interacting with their environments. The
(say robot control system 12150) that observes its environ-
ment, evaluates its current state (e.g., robot velocity, distance
to an object in front), and selects an action (e.g-, provide 65 t

change direction and the like). Upon carrying out an action,

reward (e.g., +10 for allowing sufficient space between the
robot and an obstacle in front of it and -10 for allowing
insufficient space) which provides some indication of the
success of the action. The goal for a reinforcement learning
agent is to learn an optimal policy or behavior that maxi-
mizes the expected cumulative reward.
