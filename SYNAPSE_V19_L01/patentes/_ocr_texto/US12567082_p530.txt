and/or executable. Instructions may be logically grouped
into programs, codes, methods, steps, actions, routines,
functions, libraries, objects, classes, etc. Software may be
stored by storage hardware or encoded in other hardware.

as HTML (hypertext markup language), XML (extensible
markup language), and JSON (JavaScript Object Notation),
(ii) assembly code, (ii) object code generated from source
code by a compiler, (iv) source code for execution by an

and execution by a just-in-time compiler, etc. As examples

guages including C, C++, JavaScript, Java, Python, R, etc.
