entities 652. The machine learning model 3000 may use
sensor data and user inputs to train, thereby learning which
types of sensor data are most effective for creation of digital
replicate simulations of one or more of the value chain
entities 652.For example, the machine learning model 3000
may find that a particular value chain entity 652 has dynamic
properties such as component wear and throughput affected
by temperature, humidity, and load. The machine learning
model 3000 may, through machine learning, prioritize col-
lection of sensor data related to temperature, humidity, and
load, and may prioritize processing sensor data of the
prioritized type into simulation data for output to the digital
twin system 1700. In some embodiments, the machine
learning model 3000 may suggest to a user of the informa-
tion technology system that more and/or different sensors of
the prioritized type be implemented in the information
technology and value chain system near and around the
value chain entity 652 being simulation such that more
and/or better data of the prioritized type may be used in
simulation of the value chain entity 652 via the digital
replica thereof.
