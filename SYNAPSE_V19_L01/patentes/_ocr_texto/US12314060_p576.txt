In response to a determination at 21416' that the intelli-
gent processing of the second configured intelligence service
CIS2 has provided adequate intelligence in response to the
intelligence request, the CSS2 is configured to determine at
21420' whether an action is available to fulfill the directed
action request from the primary system 21100'. When there
is an action available to fulfill the directed action request at
21420', the CSS2 proceeds to 21424'. On the other hand, if
an action is not available at 21420' to fulfll the directed
action request, the CSs2 may perform directed action pro-
cess configuration and/or directed action resource analysis
assistance using one or more additional system services at
21422' (e.g., shown as CSS5, CSS6, and CSS(n). Here,
these additional system services may be another SOS or an
external service.
At 21420', when the CSS2 determines that there is an
action available to fulfill the directed request, the process
proceeds to 21424'. Here, at 21424', the CSS2 initiates
and/or executes a process determined by or based on the
available action and/or the intelligent processing response
from the second configured intelligence service CIS2.
Optionally, as shown at 21426t and 21428', the process
that is to be initiated or executed can undergo an optimiza-
tion operation. For example, at 21428', the second config-
ured intelligence system CIS2 determines whether the
directed action process is an optimized process. In some
implementations, to determine whether the directed action
process is an optimized process, the CSS2 determines
whether the process satisfies a set of optimization con-
straints. In other implementations, the CSS2, at 21428',
determines whether the process satisfies a designed objec-
tive function. In some instances, the objective function is
based on the primary task (e.g., in combination with any
external controls included in the primary system input
21102'). In other instances, the objective function is based on
the secondary task specified by the directed action request
from the sub-level computing device input 21202°.
