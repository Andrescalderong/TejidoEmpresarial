includes a range of communication tools that permit one 60

the interface layer 21350' includes a plurality of application
programming interfaces (APIs) that allow software associ-

between two CSSs or between two SOS systems). APIs are

typically designed to standardize the way programmers/
developers interact with a platform (e.g., a software appli-
cation). In other words, prior to APIs, programmers/devel-
opers would likely have to customize the manner in which
they interact or connect with the services of an application.
With APIs, there are typically technical specifications in the
form of documentation that is associated with the API that
specifies how to integrate with the API. When using an
application, a user may initiate a task/service from the
application that generates a request. The API associated with
the application may then make a call that relays the request
to a destination or API endpoint (e.g., a uniform resource
locator (URL) of a server). Upon receipt of the request, the
API endpoint facilitates the execution of the task (e.g., by a
third-party application or database that provides the task/
service). From that perspective, APIs can ease the develop-
ment and user experience by connecting disparate system
(e.g., disparate software applications). In other words, by
using an API, the entity configuring a system or application
to perform a service can integrate the functionality of other
systems without having to design those systems' function-
ality in-system. Some examples of APIs that the interface
layer 21350'may include are Web APIs used to access web
browsers or web-based devices, Simple Object Access Pro-
tocol (SOAP) APIs that use extensible markup language
(XML) and XML schema to perform calls and structure
payloads, Open APIs (also known as public APIs), Repre-
sentative State Transfer (REST) APIs that use stateless
communication protocols, JavaScript Objection Notation
(JSON)-Remote Programming Calls (RPC) for asynchro-
nous server calls, and other custom APIs. By making an
array of APIs accessible to portions of the stack 21300t, the
interface layer 21350' helps ensure that the language of one
system is capable of being translated to a language of
another system. Otherwise, the set of systems deployed in a
given instance of the management stack 21300' may have
communication compatibility issues or suffer from the
inability to cooperatively integrate cross-functionality.
