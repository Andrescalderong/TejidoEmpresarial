Each of the organic analysis circuit 9322, lab analysis
circuit 9324, electromechanical analysis circuit 9326, and/or
environmental analysis circuit 9328 may use one or more
Al-assisted techniques to perform analyses, determine/pre-
dict conditions, predict the effects of treatments/mainte-
nance/preventative actions, and/or the like. For example,
one of the circuits may configure (e.g., using configuration
parameters specified by an analytics library) a first Al-
assisted technique to detect a particular condition (e.g., a
gradient-boosted trees model), and then the same or another
circuit may use a different Al-assisted technique (e.g., a
neural network trained using deep learning techniques) to
predict the response to a treatment plan for the particular
condition. Similarly, the chip 9300 may use multiple AI-
assisted techniques in order to perform the same tasks in
order to improve the accuracy of diagnostic information.
Thus, by leveraging multiple Al-assisted techniques, the
chip 9300 may be capable of performing complex and
highly accurate workflows that leverage different Al-as-
sisted techniques.
